# Checklist de diagnóstico do perfil

Use para pontuar rapidamente (✔ / ⚠ / ✘) e priorizar correções por impacto.

## Alto impacto (arrumar primeiro)
- [ ] **Foto**: rosto visível, fundo limpo, boa luz, sorriso natural.
- [ ] **Headline**: cargo/especialidade + valor entregue + 2–3 palavras-chave de busca (não só "Analista na Empresa X").
- [ ] **Sobre**: primeiras 3 linhas com gancho; público-alvo claro; prova (números); chamada para ação/contato.
- [ ] **Experiência atual**: 3–5 bullets com resultado mensurável.
- [ ] **Competências**: 30–50 adicionadas, 3 fixadas alinhadas ao objetivo.
- [ ] **Localização e setor** coerentes com onde quer ser encontrado.

## Médio impacto
- [ ] Banner personalizado (proposta de valor ou área de atuação).
- [ ] URL personalizada (linkedin.com/in/nome-sobrenome).
- [ ] Destaques (Featured): projeto, artigo, portfólio, case.
- [ ] Formação, cursos e certificações relevantes e atuais.
- [ ] Recomendações (pelo menos 2–3 de gestores/clientes/colegas).
- [ ] Idiomas listados com nível.

## Consistência
- [ ] Datas e cargos batem com o CV.
- [ ] Mesmo posicionamento no headline, Sobre e competências fixadas.
- [ ] Sem erros de português/inglês; sem excesso de siglas internas.
- [ ] Open to Work configurado de forma adequada (visível só para recrutadores, se o usuário preferir discrição).
